# Advanced Usage

Deep dive into shortcuts, split views, and search.

## Split View Configuration

Toggle between side-by-side editing and reading with `⌥⌘E`.

| Mode | Shortcut | Behavior |
| :--- | :--- | :--- |
| Read/Write Toggle | `⌘E` | Switches between reader and Monaco editor |
| Side-by-Side | `⌥⌘E` | Splits screen into dual synchronized panes |
| Quick Find | `⌘F` | Opens Safari-style floating find bar |
