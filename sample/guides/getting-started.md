# Getting Started Guide

Quickstart steps for navigating markdown workspaces.

## Step 1: Open a Workspace

Open the `sample/` folder using:
1. Native menu: **File ▸ Open Folder…** (⌘O)
2. Toolbar folder icon button
3. Welcome screen primary button

## Step 2: Navigate Files

Click any file in the sidebar or follow wikilinks like [[README]] or [[advanced-usage]].

## Step 3: Check Tasks

Track your progress in [[tasks|The Task Tracker]] or jump to [[tasks#urgent-tasks|Urgent Tasks]].
