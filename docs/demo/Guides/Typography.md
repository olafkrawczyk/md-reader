# Typography Guide

md-reader is a reader first. These are the knobs that make long documents
comfortable.

## Reading settings

- **Font** — Lexend or Atkinson Hyperlegible
- **Size** — S, M, L, or XL
- **Text tint** — soften the default black
- **Line height** — loosen or tighten leading
- **Measure** — control the line length
- **Focus mode** — dim everything but the block you're reading
- **Bionic reading** — bold word onsets to guide the eye

## Why measure matters

A line that runs the full width of a 27-inch display is exhausting to read.
Constraining the measure keeps the eye's return sweep short, which is why
every serious reading app ships the control.
