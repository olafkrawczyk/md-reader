# Getting Started

Three steps and you're reading.

1. **Open a folder** — `⌘O`, or launch from a terminal with
   `md-reader ~/notes`.
2. **Pick a document** in the sidebar. A single click previews it; a
   double click keeps the tab open.
3. **Choose a layout** — Read, Write, Split, or Research — from the
   toolbar or with `⌘E` and `⌥⌘E`.

## Keyboard shortcuts

| Keys        | Action                          |
| ----------- | ------------------------------- |
| `⌘O`        | Open folder                     |
| `⌘S`        | Save document                   |
| `⌘E`        | Toggle reader / editor          |
| `⌥⌘E`       | Toggle side-by-side split       |
| `⌘F`        | Find in document                |
| `⌘N`        | New file                        |
| `⌘⇧N`       | New folder                      |
| `⌘←` / `⌘→` | Previous / next tab             |
| `⌃Tab`      | Next tab (`⌃⇧Tab` for previous) |
| `⌘W`        | Close tab                       |

## Saving

Edit a document and md-reader autosaves after a short idle pause. Close a
tab or quit the app with unsaved changes and you'll get a save / discard /
cancel prompt instead of silent loss.
